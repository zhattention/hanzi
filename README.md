# 汉字学习测试工具

一个简单而有趣的汉字学习测试工具，帮助学生测试和巩固汉字认知。

## 功能特点

- 按课程选择测试汉字
- 实时计时和评分系统
- 可爱的猫咪动画效果
- 声音反馈
- 详细的测试结果统计
- 支持"认识"、"不确定"和"不认识"三种回答方式

## 使用方法

1. 选择要测试的课程（可多选）
2. 点击"开始测试"按钮
3. 在规定时间内判断是否认识显示的汉字
4. 测试结束后查看详细统计结果

## 技术栈

- HTML5
- CSS3
- JavaScript (原生)
- 动画效果
- 音效系统

## 本地运行

1. 克隆仓库：
   ```bash
   git clone https://github.com/zhattention/hanzi.git
   ```

2. 在浏览器中打开 index.html 文件
